Requires the [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) for native runs — or skip straight to [Docker](#docker).

**Run directly with `dnx` (recommended — no install step):**

```bash
dnx GroupDocs.Conversion.Mcp --yes
```

Pulls the latest stable release on every invocation. To pin to a specific
version (recommended for shared configs and CI), append `@<version>`:

```bash
dnx GroupDocs.Conversion.Mcp@26.7.2 --yes
```

### Claude Desktop

Add to `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "groupdocs-conversion": {
      "type": "stdio",
      "command": "dnx",
      "args": ["GroupDocs.Conversion.Mcp", "--yes"],
      "env": {
        "GROUPDOCS_MCP_STORAGE_PATH": "/path/to/documents"
      }
    }
  }
}
```

> To use a license, add `"GROUPDOCS_LICENSE_PATH": "/path/to/GroupDocs.Total.lic"` to `env` —
> omit it to run in [evaluation mode](#licensing).

### Claude Code

```bash
claude mcp add groupdocs-conversion -- dnx GroupDocs.Conversion.Mcp --yes
```

### Docker

```bash
docker run --rm -i \
  -v $(pwd)/documents:/data \
  ghcr.io/groupdocs-conversion/conversion-net-mcp:latest
```

Images are published to both GHCR (`ghcr.io/groupdocs-conversion/conversion-net-mcp`) and
Docker Hub (`groupdocs/conversion-net-mcp`) for `linux/amd64` + `linux/arm64`, tagged
`latest` plus an immutable version tag matching each NuGet release (e.g. `:26.7.2`).

### Global dotnet tool

```bash
dotnet tool install -g GroupDocs.Conversion.Mcp
groupdocs-conversion-mcp
```

> **Version pinning:** in any snippet above, replace `"GroupDocs.Conversion.Mcp"` with
> `"GroupDocs.Conversion.Mcp@26.7.2"` to lock to a specific release. Pinning is recommended
> for shared / committed configs to avoid surprise upgrades.

## Available MCP Tools

| Tool | Description |
|---|---|
| `Convert` | Converts a document to a different format (PDF, DOCX, XLSX, PPTX, HTML, PNG, JPG, and 70+ more) and saves the result to storage |
| `GetSupportedFormats` | Lists every target format the source document can be converted to, with primary/secondary indicators |
| `GetDocumentInfo` | Returns file type, page count, and basic properties (author, title, dates, password-protected) for a source document |

## Licensing

**The MCP server itself is MIT; the underlying GroupDocs.Conversion engine requires a license
for production use.** Without one the server runs in **evaluation mode**:

- Converted output carries an evaluation watermark, and tool responses include an
  evaluation-mode notice.
- A single server process can open at most **15 documents**; further calls fail with
  *"Could not open more than 15 document files in evaluation mode"* until the server restarts.

To lift the limits, point `GROUPDOCS_LICENSE_PATH` at your `GroupDocs.Total.lic` (see the
commented example in each install snippet above):

- [Get a free 30-day temporary license](https://purchase.groupdocs.com/temporary-license/)
- [Purchase a license](https://purchase.groupdocs.com/pricing/conversion/net) · [Product page](https://products.groupdocs.com/conversion/net/)

## Configuration

| Variable | Description | Default |
|---|---|---|
| `GROUPDOCS_MCP_STORAGE_PATH` | Base folder for input and output files | current directory |
| `GROUPDOCS_MCP_OUTPUT_PATH` | *(Optional)* separate folder for output files | `GROUPDOCS_MCP_STORAGE_PATH` |
| `GROUPDOCS_LICENSE_PATH` | Path to GroupDocs license file | (evaluation mode) |

## Native prerequisites

The underlying GroupDocs engine uses `System.Drawing` (GDI+) for some
operations. When you run the server **natively** (via `dnx` or the global
dotnet tool) on Linux or macOS, install the native `libgdiplus` library first:

| Platform | Setup |
|---|---|
| Windows | Nothing — GDI+ is built into the OS. |
| Linux | `sudo apt-get install -y libgdiplus libfontconfig1 ttf-mscorefonts-installer` |
| macOS | `brew install mono-libgdiplus` |
| Docker | Nothing — the image already bundles `libgdiplus`. |

Skipping this on Linux/macOS surfaces as `DllNotFoundException: libgdiplus` in
the tool response. The simplest zero-setup option on Linux/macOS is the
**Docker image**.

## Usage with Docker Compose

```bash
cd docker
docker compose up
```

Edit `docker/docker-compose.yml` to point volumes at your local documents folder.
